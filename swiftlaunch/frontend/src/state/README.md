# Frontend State Management (Zustand)

Global state stores built with Zustand for clean, lightweight reactive state.

## Files
- **`useSearchStore.ts`**: Core launcher store containing active query, search results, selected item index, loading states, and category groupings.
- **`useComboStore.ts`**: Manages user-configured App Combos (e.g. creating, saving, deleting, and loading clubbed apps).
- **`useUiStore.ts`**: Manages UI preferences such as Dark/Light theme toggles and display settings.
